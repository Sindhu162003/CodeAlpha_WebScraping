# Book Web Scraper

## Description
This project scrapes book details from the "Books to Scrape" website using Python.

## Features
- Extracts book titles
- Extracts prices
- Extracts ratings
- Extracts availability
- Saves the data into a CSV file

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Output
The scraped data is stored in `books.csv`.
